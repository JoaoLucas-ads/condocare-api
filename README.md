# 📌 Sobre o Projeto

O VSAR Condo é um sistema de gestão de chamados prediais desenvolvido para facilitar a comunicação entre moradores, técnicos e administradores de condomínios.

A plataforma permite o registro, acompanhamento e gerenciamento de ocorrências, garantindo maior controle dos atendimentos, rastreabilidade das ações realizadas e geração de indicadores para apoio à gestão.

---

# 🎯 Objetivo

Centralizar o processo de abertura, atendimento e auditoria de chamados prediais, proporcionando mais organização, transparência e eficiência operacional.

---

# 👥 Perfis de Usuário

## Morador

* Abertura de chamados.
* Consulta de solicitações.
* Acompanhamento dos atendimentos.

## Técnico

* Visualização de chamados atribuídos.
* Início do atendimento.
* Reagendamento de chamados.
* Finalização de atendimentos.
* Registro de laudo técnico e observações.

## Administrador / Síndico

* Gerenciamento completo dos chamados.
* Atribuição de técnicos.
* Acompanhamento de indicadores.
* Acesso ao módulo de relatórios.

# 🔄 Fluxo do Sistema

1. Morador abre um chamado.
2. Administrador atribui um técnico.
3. Técnico inicia o atendimento.
4. Técnico registra laudo técnico e observações.
5. Técnico finaliza o chamado.
6. O sistema registra todo o histórico da operação.
7. Os dados alimentam os relatórios gerenciais.
