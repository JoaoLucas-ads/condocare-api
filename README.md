# 📌 Sobre o Projeto

O VSAR Condo é um sistema de gestão de chamados prediais desenvolvido para facilitar a comunicação entre moradores, técnicos e administradores de condomínios.

A plataforma permite o registro, acompanhamento e gerenciamento de ocorrências, garantindo maior controle dos atendimentos, rastreabilidade das ações realizadas e geração de indicadores para apoio à gestão.

---

# 🎯 Objetivo

Centralizar o processo de abertura, atendimento e auditoria de chamados prediais, proporcionando mais organização, transparência e eficiência operacional.

---

# 👥 Perfis de Usuário

## Morador

* Abertura de chamados.
* Consulta de solicitações.
* Acompanhamento dos atendimentos.

## Técnico

* Visualização de chamados atribuídos.
* Início do atendimento.
* Reagendamento de chamados.
* Finalização de atendimentos.
* Registro de laudo técnico e observações.

## Administrador / Síndico

* Gerenciamento completo dos chamados.
* Atribuição de técnicos.
* Acompanhamento de indicadores.
* Acesso ao módulo de relatórios.

---

# 🚀 Funcionalidades Implementadas

## Gestão de Chamados

* Cadastro de chamados.
* Controle de status:

  * Aberto
  * Em Atendimento
  * Reagendado
  * Finalizado
* Histórico completo de alterações.
* Controle de responsáveis.

## Atendimento Técnico

* Atribuição de técnicos.
* Registro de laudo técnico.
* Registro de observações.
* Alteração de status.
* Finalização de chamados.

## Dashboard

* Total de chamados.
* Indicadores rápidos.
* Navegação simplificada.

## Avisos

* Centralização de comunicados.
* Alertas operacionais.

## Relatórios Gerenciais

* Total de chamados.
* Chamados abertos.
* Chamados em atendimento.
* Chamados reagendados.
* Chamados finalizados.
* Chamados com técnico.
* Chamados sem técnico.
* SLA médio.
* Produtividade por técnico.
* Principais defeitos recorrentes.

## Auditoria

* Histórico de alterações.
* Registro de quem abriu o chamado.
* Registro de quem realizou o atendimento.
* Registro de alterações de status.

# 📊 Indicadores Disponíveis

## SLA Médio

## Produtividade por Técnico

Quantidade de chamados finalizados por técnico.

## Principais Defeitos

Ranking dos problemas mais recorrentes registrados no sistema.

---

# 🔄 Fluxo do Sistema

1. Morador abre um chamado.
2. Administrador atribui um técnico.
3. Técnico inicia o atendimento.
4. Técnico registra laudo técnico e observações.
5. Técnico finaliza o chamado.
6. O sistema registra todo o histórico da operação.
7. Os dados alimentam os relatórios gerenciais.

# 🎓 Projeto Acadêmico

Projeto desenvolvido para a disciplina de Projeto Integrador do curso de Análise e Desenvolvimento de Sistemas (ADS).

O sistema foi concebido para aplicar conceitos de desenvolvimento mobile, APIs REST, banco de dados, controle de acesso por perfis, auditoria de processos e geração de indicadores gerenciais voltados para a gestão condominial.
